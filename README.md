# Global Superstore Sales Analysis | Power BI Dashboard

## Project Overview

This project presents an interactive Sales Analysis Dashboard developed using **Microsoft Power BI**. The dashboard analyzes the Global Superstore dataset to understand sales performance, profitability, product categories, customer segments, and regional business performance.

The main objective is to transform raw sales data into meaningful insights that support better business decision-making.

## Tools & Technologies

- Microsoft Power BI
- Microsoft Excel
- Data Cleaning and Transformation
- Data Visualization

## Dashboard Features

- **Sales Analysis:** Analyze overall sales performance.
- **Profit Analysis:** Understand profit distribution and profitability.
- **Category Analysis:** Compare performance across different product categories.
- **Regional Analysis:** Explore sales performance across different geographical regions.
- **Customer Analysis:** Analyze customer segments and their contribution to sales.
- **Interactive Charts:** Explore business data through visualizations.

## Project Files

- `reprt.pbix` – Complete Power BI dashboard file.
- `dashboard-preview.png` – Dashboard preview image (if uploaded).

## How to Use

1. Download the `.pbix` file from this repository.
2. Open Microsoft Power BI Desktop.
3. Open the downloaded Power BI file.
4. Explore the dashboard and interact with the visualizations.

To develop practical skills in data analysis, data visualization, and business intelligence using Microsoft Power BI.
